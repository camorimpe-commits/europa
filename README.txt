# Eurotrip 2026 - versão pronta para Vercel/PWA

## Como publicar
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta.
3. Na Vercel, clique em **Add New Project**.
4. Conecte o repositório e faça o deploy.
5. Abra o link no celular e escolha **Adicionar à tela inicial**.

## Arquivos
- `index.html`: app principal
- `manifest.webmanifest`: configuração de instalação no celular
- `sw.js`: cache offline básico
- `icon-192.png` e `icon-512.png`: ícones do app
- `vercel.json`: configuração simples da Vercel
